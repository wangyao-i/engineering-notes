# Qwen3-ASR-1.7B 昇腾 A3 性能调优结果（2026-11-23）

[English](qwen3-asr-ascend-tuning-results-2026-11-23.en.md) | 更新：2026-11-23

本文整理昇腾 A3 单 die 上 Qwen3-ASR-1.7B 三种配置的性能与精度对比，并记录 A-B-B-A 交叉测试的波动。数据来自一次操作者报告；本文没有重新运行硬件测试。

## 结论概览

B2b 面向高并发吞吐，不启用 DFlash；B3 在 B2b 上增加 DFlash（draft 8），侧重低并发延迟和识别精度。两种候选配置的重复测试波动较大，结果不构成服务级延迟承诺。

| 配置 | 主要改动 | C1 延迟 | C64 延迟 | C64 吞吐 | CER |
|---|---|---:|---:|---:|---|
| B0 基线 | 无专用编码器服务、prefill 图或 DFlash | 128 ms | 2094 ms | 30.20 req/s | C1–C64 为 0.0036–0.0226 |
| B2b 吞吐优先 | 专用编码器服务、breakable prefill 图、关闭异步解码；无 DFlash | 114 ms | 526–716 ms | 摘要报告 87–119 req/s；单次结果表为 122.10 req/s | C1 0.0248；C64 0.0036–0.0038 |
| B3 精度优先 | B2b 加 DFlash，draft 8 | 62 ms | 958–1628 ms（A-B-B-A 均值 1293 ms） | 摘要约 65 req/s；单次结果表为 81.56 req/s | 报告各档均为 0.0036 |

摘要吞吐范围与单次结果表的吞吐数值不同，以下分开记录，不能合并为一个点估计。

## 分档性能与精度

| 并发 | B0 延迟 / CER | B2b 延迟 / CER | B3 延迟 / CER |
|---:|---|---|---|
| 1 | 128 ms / 0.0226 | 114 ms / 0.0248 | 62 ms / 0.0036 |
| 16 | 662 ms / 0.0067 | 332 ms / 0.0119 | 450 ms / 0.0036 |
| 32 | 1404 ms / 0.0075 | 494 ms / 0.0048 | 1139 ms / 0.0036 |
| 64 | 2094 ms / 0.0036 | 508 ms / 0.0040 | 单次 769 ms；A-B-B-A 为 958–1628 ms |

## 单次结果吞吐

| 并发 | B0 (req/s) | B2b (req/s) | B3 (req/s) |
|---:|---:|---:|---:|
| 1 | 7.80 | 8.79 | 15.96 |
| 16 | 23.96 | 47.80 | 35.37 |
| 32 | 22.62 | 63.67 | 26.43 |
| 64 | 30.20 | 122.10 | 81.56 |

B3 的单次吞吐会随延迟波动；摘要中的约 65 req/s 与单次表中的 81.56 req/s 分别保留各自报告口径。

## A-B-B-A 稳定性

| 指标 | B0 | B2b | B3 |
|---|---:|---:|---:|
| C64 延迟两次观测 (ms) | 1984 / 2100 | 716 / 526 | 958 / 1628 |
| C64 两次运行差异 | 5.7% | 30.6% | 51.8% |
| 相对 B0 的 C32 加速比 | — | 2.17× | 1.07× |
| 相对 B0 的 C64 加速比 | — | 3.29× | 1.40× |

B2b 的 C64 吞吐较高；B3 在报告测试档位的 CER 为 0.0036，且 C1 延迟更低。两种候选配置的运行间波动都较大，B3 尤其明显。选择配置时应同时考虑吞吐、精度、尾延迟和复现稳定性。

## 配置与测试范围

| 项 | 报告配置 |
|---|---|
| 硬件 | 昇腾 A3（Atlas 800I A3），单 die；测试期间独占主机 CPU |
| 软件 | openEuler 22.03 LTS-SP4 aarch64；驱动 26.0.rc1 / ascendhal 7.35.23；CANN 9.1.0；Python 3.12；torch 2.10.0 / torch_npu 2.10.0.post6；SGLang 0.5.23；SGLang-Omni 0.2.0；transformers 5.19.0 |
| 数据 | Seed-TTS-Eval 中文；每档报告 640 条请求；单 die；音频均值 4.79 秒 |
| B2b | `enable_async_decode: false`、`enable_pre_lm_encoder: true`，prefill 图为 `breakable`，无 DFlash |
| B3 | B2b 配置上启用 DFlash，draft token 数为 8 |
| 交叉测量 | A-B-B-A；每种候选配置 C64 两段结果已列于上表 |

完整配置、调优步骤、CER 归因、无效配置和复现检查清单见 [roadmap 中的完整测试记录](https://github.com/sgl-project/sglang-omni/issues/2076)。

## 限制

| 项目 | 当前证据边界 |
|---|---|
| 重复性 | A-B-B-A 中 B2b 的 C64 差异 30.6%，B3 为 51.8%；B0 为 5.7% |
| 图路径正确性 | 测试启用 prefill 图并将 decode 图桶扩至 64；这超出已合入 NPU DFlash 配置的原验证范围，需按目标环境自行回归 |
| 设备扩展 | 只测一个 die，未验证多 die 扩展 |
| 样本和负载 | 报告每档 640 个请求，A-B-B-A 每配置仅两段；中文、均值 4.79 秒音频，长音频未覆盖 |
| 其他 | 未记录显存峰值和 DFlash 接受率；精确镜像、代码与模型 revision 需另行固定 |

此前的七档单次 DFlash 性能记录保留在 [2026-11-20 双语复现说明](qwen3-asr-ascend-dflash-reproduction-2026-11-20.zh-CN.md) 中；其 workload/configuration 与本文三配置调优实验不同。
